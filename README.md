# PNCP Kaggle: processamento integrado ao Descoberta Pública

O material deste trabalho está integrado ao projeto principal, sem criar uma base concorrente neste repositório:

- **Projeto e avisos:** https://github.com/viniburilux/descoberta-publica#fonte-adicional-snapshot-pncp-do-kaggle
- **Código, método e procedência:** https://github.com/viniburilux/descoberta-publica/tree/main/fontes/kaggle_pncp
- **Dados processados e manifestos:** https://github.com/viniburilux/descoberta-publica/releases/tag/kaggle-pncp-v0.1.0

São 3.768.885 contratações do snapshot de 30/09/2026, 18 modalidades presentes, organizadas em 69 Parquets. A base original de 494.446 permanece separada e não foi alterada.

## Crédito à coleta

O mérito da coleta e da disponibilização do snapshot é de **Lucas Rangel S. Souza**:

- https://www.kaggle.com/datasets/lucasrangelss/pncp-raw-trusted-part-1
- https://github.com/LucasRangelSSouza/brazil-public-data-map

A fonte primária é o PNCP. O processamento derivado é do Descoberta Pública.

## Limites

O Kaggle informa "Other (specified in description)" e "Source terms apply; credit the original publisher". Não se atribui licença aberta nova aos dados de terceiros. As máscaras não anonimizam nomes nem garantem remoção de todo dado pessoal. A classificação v6.3 não foi validada nas outras modalidades e tem falsos positivos como "banda larga" e "forro". Há 3.978 IDs do trusted sem linhagem explicada pelo raw de atualização disponível. Leia os avisos completos no projeto principal antes de usar.

Este repositório foi mantido apenas como ponte. Os dados derivados estão no Descoberta Pública, não aqui.
